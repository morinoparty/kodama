# スタイリング

## 基本方針

- スタイルは Tailwind CSS v4 のユーティリティクラスで記述してください。CSS in JS は使いません。
- 色・フォント・角丸などのデザイントークンは `src/styles.css` の `@theme` と CSS 変数
  (`var(--sea-ink)` / `var(--line)` など) に定義されています。生の色値を直接書かず、
  できるだけ既存のトークンを使ってください。
- 繰り返し使うパターン (`page-wrap` / `island-shell` / `nav-link` など) は
  `src/styles.css` に定義済みのクラスがあります。新しく作る前に既存のものを探してください。
- ダークモードは `html` 要素の `light` / `dark` クラスで切り替わります (`src/components/theme-toggle`)。
  片方のテーマでしか成立しない配色にしないでください。

## レスポンシブ

- モバイルファーストで記述し、`sm:` / `lg:` などのブレークポイントで拡張してください。
- 横スクロールが発生しないようにしてください。表やコードブロックは個別に
  `overflow-x: auto` のコンテナに入れてください。

## 文言

- 画面に表示する文言は日本語で書いてください。
